# Calculadora Tkinter

Primeiro projeto GUI desenvolvido com Python

## Tecnologias utilizadas
- Python
- Tkinter

## Funcionalidades
- Soma
- Subtração
- Divisão
- Multiplicação
- Raiz Quadrada
- Exponenciação
- Números Negativos
- Interface Gráfica

## Objetivo
Projeto criado para praticar:
- Lógica de programação
- Modularização
- Interfaces gráficas
- Organização de código
